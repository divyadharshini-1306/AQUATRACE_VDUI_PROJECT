# Accessibility checklist (per page)
- [ ] Alt text on every visual (Format > General > Alt text)
- [ ] Tab order set (View > Selection pane / Tab order) and logical
- [ ] Contrast ratio at least 4.5:1 for text
- [ ] Risk tiers shown with labels/icons, not colour alone
- [ ] Clear insight title, labelled axes, no chart junk
- [ ] "Modelled estimates" in subtitle and footnote
