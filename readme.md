# AquaTrace 
### Data-Driven Analysis of Data Center Water Risk

## Problem Statement
Data centers consume significant amounts of water for cooling. Limited facility-level water-use information makes it difficult to identify water-risk patterns and understand which factors contribute to higher risk.

**AquaTrace** uses data analysis and visualization to explore water consumption, cooling efficiency, and water risk across data centers.

## Tech Stack
- **Python:** Data analysis and preprocessing
- **Pandas & NumPy:** Data manipulation
- **SciPy:** Statistical analysis
- **Matplotlib:** Data visualization
- **Power BI:** Interactive dashboard
- **Git & GitHub:** Version control
- **Power BI**
